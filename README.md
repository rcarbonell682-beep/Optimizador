# Optimizador

App Android (Java puro, sin XML de layouts) que usa Shizuku para optimizar el teléfono.

Funciones: forzar 4G (abre la pantalla Información del teléfono), compilar apps, cerrar apps, limpiar caché, bloquear segundo plano por app,
desactivar bloatware, ahorro extremo de datos y brillo (activar/revertir) y monitor de RAM/temperatura.

Compilar: sube todo a GitHub -> Actions -> "Build APK" -> Artifacts -> Optimizador-APK.
